1. Business Understanding

Problem Statement

Job seekers spend 2–4 hours per application manually tailoring their resume and writing a cover letter for each job posting. With the average job search requiring 100–200 applications, this represents a massive time investment that often leads applicants to send generic materials, reducing their chances of getting interviews.

Business Need

  • For job seekers: Reduce application preparation time from hours to minutes while maintaining quality, personalization, and factual accuracy.
  • For career services: Provide a scalable tool that helps students and professionals apply more effectively without one-on-one counseling for each application.
  • Market gap: Existing tools either generate generic content (template fillers) or require manual prompting for each section (ChatGPT copy-paste). No tool offers an end-to-end pipeline from job URL to submission-ready documents with quality checks.

Objectives

  1. Automate resume tailoring — Match and rewrite resume bullets to job requirements using only facts from the original resume. No fabrication of experience.
  2. Generate personalized cover letters — Create role-specific letters that reference company research and map candidate strengths to job needs.
  3. Assess candidate fit — Score how well the candidate meets each requirement before they invest time applying.
  4. Self-evaluate and revise — Automatically review generated documents, score them, and revise weak sections.
  5. Track applications — Maintain a history with status tracking, duplicate detection, and semantic similarity search.

Stakeholders

Success Criteria

  • Resume tailoring preserves factual accuracy (fabrication check built in)
  • Cover letters are role-specific, not generic templates
  • Fit assessment correctly identifies met vs. missing requirements
  • End-to-end pipeline runs in under 3 minutes
  • Application history prevents duplicate submissions (exact + semantic match)
  • Deployed and accessible via web browser

2. Project Understanding

Approach

The project uses LangGraph, a graph-based orchestration framework for LLM workflows, to build a multi-step agent pipeline. Each processing step is a node in a directed acyclic graph (with one revision loop). Conditional edges control the flow based on intermediate results—for example, skipping the pipeline if the user already applied to the same job, or revising documents if the self-evaluation score is below threshold.

Key Design Decisions

DecisionRationale
LangGraph orchestrationEnables parallel execution, conditional branching, human-in-the-loop interrupts, and persistent checkpoints—all in one framework.
Multi-provider LLM supportGemini (free, high limits), OpenAI (quality), Groq (speed). Users choose based on their constraints.
Pydantic structured outputsEvery LLM response is validated against a schema. No unstructured text parsing.
No fabrication guaranteeThe resume tailor is constrained to rearrange and rephrase existing content only. Fabrication warnings are flagged.
Human-in-the-loopNothing is submitted without explicit user approval. Users can edit, revert changes, or request revisions.
Local vector storeFAISS + FastEmbed for semantic duplicate detection without external API calls or data leaving the machine.

5. Final Outcome

Delivered System

The Autonomous Job Application Agent is a fully functional, deployed web application that takes a resume and job posting as input and produces tailored, submission-ready application materials.

Key Deliverables

  • Streamlit Web Application — Interactive UI with resume upload, real-time progress tracking, document preview, inline editing, and PDF/DOCX download.
  • Command-Line Interface — Full-featured CLI for batch processing and automation (main.py).
  • Docker Container — Production-ready container deployed on Render with password protection.
  • Application History — Persistent tracking of all applications with status updates, fit scores, and duplicate detection.

Ethical Safeguards

  • No fabrication: The system only rearranges and rephrases existing resume content. Fabrication warnings are generated and displayed.
  • Human control: Every application requires explicit approval. Users can edit documents, revert changes, or reject entirely.
  • Anti-spam: Application history with duplicate detection prevents bombarding the same employer.
  • Transparency: All changes are shown as before/after diffs. Users see exactly what was modified.

Deployment

Live Application: The system is deployed on Render as a Docker container. It uses the Groq LLM provider (free tier) and is password-protected for controlled access. Users can access it through any web browser.
